# Mingle

**Mingle** is a modern, full-featured social media app that brings people together through posts, messages, and real-time interactions. Whether you're sharing moments, exploring communities, or building your network, Mingle provides a smooth and engaging experience.

## 🌟 Features

- 🔐 User authentication (sign up, login, logout)
- 🖼️ Create, like, comment, and share posts
- 💬 Real-time chat and messaging
- 👥 Follow and connect with other users
- 📱 Mobile-responsive design
- 🧠 Smart feed powered by user activity
- 🔔 Notification system
- ⚙️ Profile customization

## 🚀 Tech Stack

- **Frontend:** React, Redux, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT (JSON Web Tokens)
- **Real-time Features:** Socket.IO
- **Storage:** Cloudinary for image uploads
